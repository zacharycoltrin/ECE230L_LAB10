## Lab Questions

### What is difference between edge and level sensitive circuits?
Level sensitive circuits only allow changes if the enable signal is high, while edge sensitive circuits only allows change when the enable is changing from low to high.

### Why is it important to declare initial state?
It is important to declare initial state because when the board is being programmed, it has no knowledge about the state of any of the memory inside. The memory inside is random and it will mess with our program on hardware.

### What do edge sensitive circuits let us build?
Edge sensitive circuits let us build flip flops, such as the ones from this lab, and allows us to build synchronous digital systems.
